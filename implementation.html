Design Iteration from Low-Fi to High-Fi

The transition from low-fidelity to high-fidelity prototypes was guided by user feedback and usability principles:

  1. 01

    The initial low-fidelity design focused on basic layout and functional structure.

  2. 02

    Based on feedback, the high-fidelity version improved visual hierarchy, color richness, and interaction clarity.

  3. 03

    Key features such as the AI coach and check-in function were repositioned to the homepage for better accessibility.

  4. 04

    Gamification elements and progress visualization were enhanced to increase user motivation and engagement.

  5. 05

    This iterative process ensured that the final design better aligns with user needs and usability standards.
